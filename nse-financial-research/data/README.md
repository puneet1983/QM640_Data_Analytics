# Data storage

manifests/download_manifest.csv is the existing screened filing manifest.
raw/nse_xml_2022_2024 is a repository placeholder; Colab uses the existing
Google Drive folder /content/drive/MyDrive/nse_xml_2022_2024 instead.

reference is reserved for verified company identifiers and sector mappings.
Generated data lives on Drive and is excluded from Git by default.
